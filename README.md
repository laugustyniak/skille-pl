# Skille po polsku

Trzy gotowe skille dla Claude, ChatGPT i Gemini. Napisane po polsku, dla osób, które nie programują.

Skill to instrukcja, którą asystent AI ładuje sam, gdy zadanie do niej pasuje. Wgrywasz ją raz i działa w każdej rozmowie.

| Skill | Co robi |
|---|---|
| `pismo-do-urzedu` | Pisze wniosek, odwołanie, reklamację, ponaglenie lub wezwanie do zapłaty w układzie, którego urząd nie odeśle. |
| `przeglad-umowy` | Czyta umowę przed podpisaniem i wskazuje ryzykowne zapisy, braki i pytania do drugiej strony. |
| `post-linkedin-pl` | Pisze post na LinkedIn, który nie brzmi jak AI, albo czyści gotowy szkic ze sztucznych zwrotów. |

**Pobierz:** pliki ZIP są w zakładce [Releases](../../releases/latest).
**Zainstaluj:** instrukcja krok po kroku dla Claude, ChatGPT i Gemini w [INSTALACJA.md](INSTALACJA.md).

Skille trzymają się otwartego standardu [Agent Skills](https://agentskills.io), więc ten sam plik działa także w Claude Code, Codex i Antigravity.

Skille nie są poradą prawną. Przy ważnych sprawach pokaż pismo lub umowę prawnikowi.
